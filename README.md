# ①課題名
好き嫌いゲーム（リッチバージョン）

## ②課題内容（どんな作品か）
- 花弁を好き・嫌いとめくっていき、最後にどちらになるかで気になる子が自分のことを好きか嫌いかを占うゲーム
- 最初のクリックで花弁を表示、花の中心をクリックしていくことで花びらが減っていく。同時に好きか嫌いかがでて最終結果がでる。

## ③アプリのデプロイURL
デプロイしている場合はURLを記入（任意）


## ⑤工夫した点・こだわった点
- 最初に花弁をだすボタンと花弁をちぎるボタンの２つを用意しようと思った。それだとスペースをとるので、花の中心をボタン代わりにした。
- 初回版にはやらなかった花弁をちぎっていく様子をリッチバージョンで実現した。
- 花弁の数が１か２枚だったら花として成立しないので、5枚を最低とした（乱数の設定）。キリがないので最大９枚までとした。
