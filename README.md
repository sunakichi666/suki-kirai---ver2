# ①課題名
好き嫌いゲーム（リッチバージョン）

## ②課題内容（どんな作品か）
- 花弁を好き・嫌いとめくっていき、最後にどちらになるかで気になる子が自分のことを好きか嫌いかを占うゲーム
- 最初のクリックで花弁を表示、花の中心をクリックしていくことで花びらが減っていく。同時に好きか嫌いかがでて最終結果がでる。

## ③アプリのデプロイURL
https://sunakichi666.github.io/suki-kirai---ver2/


## ⑤工夫した点・こだわった点
- 最初に花弁をだすボタンと花弁をちぎるボタンの２つを用意しようと思った。それだとスペースをとるので、花の中心をボタン代わりにした。
- 初回版にはやらなかった花弁をちぎっていく様子をリッチバージョンで実現した。
- 花弁の数が１か２枚だったら花として成立しないので、5枚を最低とした（乱数の設定）。キリがないので最大９枚までとした。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 花弁の配置（花弁が円を描くようにきれいに配置する必要があった。また、中心のボタンに合うようにスペースを空ける必要があったが、AIに聞いた。
- .parentと.childを使った花弁とボタンの位置の調整

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
- 見た目の良し悪しは置いておいて花弁をちぎる様子は表現できるものだと思った
- 当たり前だが大がかりな使用にすればするほど大変になる。
